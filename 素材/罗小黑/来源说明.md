# 罗小黑素材来源

本目录第一批动作素材来自动作参考仓库 [opensetk/dsh-xiaohei](https://github.com/opensetk/dsh-xiaohei) 的 `assets/` 目录：

- `main-base.png`
- `main-run.gif`
- `main-wave.gif`
- `main-play-heixiu.gif`
- `main-wiggle.gif`

`processed/idle-hd.png` 是基于原待机图保持姿态和配色生成的高清透明版本；其余 `processed/*.png` 由 `tools/preprocess_xiaohei.py` 从原 GIF 放大、锐化并整理为 Sprite Sheet。

正式发布前请确认这些素材及其原始来源的使用授权。该参考仓库 README 标注其宠物素材来自其他公开资源、仅供学习交流使用。
